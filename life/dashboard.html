Using this dashboard

  

    
What you see

    
One recorded generation: every agent's life in the world on the left, and the brain of one agent (the focused agent, ringed in red) on the right. Pick an agent by clicking it in the world or from the list.

    

    
Keyboard

    

      Spaceplay / pause
      ← →one tick back / forward (with Shift: 10 ticks)
      Home Endfirst / last tick
      [ ]slower / faster
      , .previous / next agent with a brain view
      Fkeep the focused agent in view
      ?this help
      Escclose a maximised panel or this help
    

    
Mouse

    

      Worldscroll to zoom, drag to pan, double-click to fit; click an agent to focus it
      Plots, architectureCtrl + scroll (or pinch) to zoom, drag to pan, double-click to reset; in a maximised panel plain scrolling zooms. Activations: Shift zooms the neurons instead of time.
      Architecturedrag blocks to arrange them; click a block or an arrow for details; drag the bottom-right corner to resize
      Fitnessdrag to zoom, double-click to reset, hover for values, click a legend entry to hide it
      Panelsclick a header to fold it; the divider between the columns can be dragged
